# Examora Backend

Backend service for the Examora Online Examination System.

## Tech Stack

Spring Boot 3  
Spring Security + JWT  
PostgreSQL  
JPA / Hibernate  
Maven  

## Setup

1 Install dependencies

./mvnw clean install

2 Configure environment

Copy .env.example to .env

3 Run application

./mvnw spring-boot:run

Server runs at

http://localhost:8080
